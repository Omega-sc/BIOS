## 1. Deliverables Breakdown

### Phase A: Core Streamlit Dashboard & Navigation
1. **Application Shell (`ui/app.py`)**:
   - Master Streamlit interface connecting strictly to public contracts (`contracts.models`), the agent state machine stream (`run_investigation`), golden fixture reports (`fixtures/golden_report.json`), and the counterfactual simulator (`sim/`).
   - Uses `st.session_state` to maintain persistent investigation state across UI interactions (`events`, `report`, `selected_evidence_id`, `skew_corrected`).
   - **Sidebar**:
     - **Dataset Selector**: Supports primary telemetry (`data/incident.db`), tiny sample (`fixtures/tiny_telemetry.jsonl`), and canonical scenarios (`data/scenarios/*.jsonl`). Automatically handles SQLite caching for JSONL datasets.
     - **Mode Selector**: `replay` (default for instant offline demo), `scripted` (deterministic 5-node pipeline), `live` (autonomous LLM tool-calling loop).
     - **Action Buttons**: `🚀 Investigate` (streams live events), `⚡ Golden Fixture` (instant inspection), and `🔄 Reset Dashboard`.
     - **Dataset Info Card**: Shows active database, known skew, and monitored services.

2. **Left Column: Raw Unaligned Telemetry & SQLite Row Lookup (`ui/panels/raw_telemetry.py`)**:
   - **Raw Telemetry Viewer**: Filterable `st.dataframe` showing spans, logs, and metrics in unaligned wall-clock coordinates. Rows are styled with custom pandas `Styler` coloring errors (500/504/ERROR/FATAL) in light red, warnings in amber, and skewed `auth-service` records in orange. Exposes the **+12.0s clock skew** on `auth-service` and ~15% packet drop.
   - **Evidence Row Direct SQLite Lookup**: Accepts any evidence ID (`span_id`, `log_id`, or `metric@timestamp`). Fully synchronized with session state from button clicks in Post-Mortem and Timeline panels, immediately querying SQLite and rendering the raw record for 100% ground-truth auditability.

3. **Right Column: Investigation & Post-Mortem Suite**:
   - **Live Agent Stream (`ui/panels/agent_stream.py`)**: Renders streaming `AgentEvent` objects (`state`, `tool_call`, `tool_result`, `hypothesis`, `report`) with animated status indicators, badge color-coding, and expandable argument payloads.
   - **Service Dependency DAG (`ui/panels/dag_view.py`)**: Renders service call graph in Graphviz DOT format with caller $\to$ callee edge call counts, latencies, and error propagation. Highlights the localized failure frontier (`auth-service -> db-pool`, `gateway -> auth-service`, or `frontend -> gateway`) in bold crimson with specific failure signatures.
   - **Reconstructed Timeline (`ui/panels/timeline.py`)**: Interactive Plotly Gantt/Scatter chart with a dynamic **"Apply Skew Correction" toggle** and interactive clickable evidence buttons linking directly to the Left Column raw record lookup.
     - When OFF (Uncorrected): Displays the causal paradox where gateway 504 errors appear to happen *before* auth pool exhaustion.
     - When ON (Corrected): Shifts `auth-service` timestamps forward by 12s, demonstrating how apparent causality reverses and places pool exhaustion strictly *before* gateway errors.
   - **Structured Post-Mortem Report (`ui/panels/post_mortem.py`)**:
     - Clearly distinguishes `🟢 Verified Fact` from `🟡 Inference` badges.
     - Evaluated hypotheses cards with confidence bars using mandatory honest terminology: **"evidence-based score"**.
     - Clickable evidence pointers that automatically synchronize session state and populate the Left Column Evidence Lookup viewer upon clicking.
     - Actionable remediation plan list.

### Phase B: Counterfactual Simulator Panel (`ui/panels/counterfactual.py`)
1. **Dynamic Pool-Size Slider**:
   - Allows users to drag connection pool capacity from 1 to 100 (default 20).
   - Wrapped in `@st.cache_data` for instantaneous (<50ms cached, <300ms fresh) discrete-event Monte Carlo simulation.
   - Displays baseline failure probability, intervened failure probability, and 95% confidence intervals `ci95`.
   - Mandatory disclaimer: *"A model-based simulation estimate under varying parameters."*
   - Dynamic model methodology expander displaying calibrated Poisson arrival rate $\lambda$, mean service time $\mu$, pool capacity $K$, and leak probability $p_{\text{leak}}$.
2. **Side-by-Side Comparison Cards**:
   - **Card 1 (`fix_leak`)**: Failure probability drops to **0.0% (CI: [0.0%, 0.0%])**, mathematically proving the connection leak is the true root cause.
   - **Card 2 (`pool_size=50`)**: Shows delayed exhaustion over the incident window, illustrating a capacity band-aid.
   - **Card 3 (`no_retries`)**: Failure probability remains elevated (22.3%), proving client retries are an amplifier rather than root cause.


### Investigation Modes in UI
1. **Replay Mode (`replay`, Default)**:
   - Zero-network, offline streaming of pre-recorded traces from `fixtures/replay/`.
   - Recommended for hackathon presentations and offline demos.
2. **Scripted Mode (`scripted`)**:
   - Deterministic 5-node rule-based investigator executing all analytical tools (`estimate_clock_offsets`, `rank_metric_onsets`, `build_dependency_dag`, `failure_frontier`, `fit_sim_params`, `run_counterfactual`).
3. **Live Mode (`live`)**:
   - Autonomous multi-turn LLM tool-calling loop using `LLMAdapter` with disk replay caching and schema retry validation.
